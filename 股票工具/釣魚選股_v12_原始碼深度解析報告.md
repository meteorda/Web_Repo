## 壹、系統整體規格與架構藍圖

《釣魚選股 v12》是一個極具創新性與高技術密度的單檔案 Web 應用程式（Single-File Application, SFA）。它巧妙地將**「休閒釣魚遊戲視覺（Gamification）」**作為前端交互外殼，骨子裡卻是一個高度複雜且完整的**「台股全市場量化選股、籌碼追蹤、產業拓撲圖譜與 AI 大模型推論決策系統」**。

### 1. 代碼分層與三大腳本區塊

- **Block 0：主控與遊戲畫布引擎（~11,720 行）**
  - 60FPS Canvas GameLoop / 物理釣線與魚隻行為樹
  - 全市場資料抓取管線 / 備援 CORS Proxy 矩陣
  - HUD 狀態儀表板 / 導航棧 Navigation Stack
  - Web Audio API 原生音效合成系統
  - 虛擬投資組合 / 釣竿升級 / 成就系統

- **Block 1：v10-extensions 量化指標引擎（window.V10，~2,436 行）**
  - 數學指標引擎：DMI, MACD, CCI, OBV, 布林通道, Fibonacci 黃金分割線
  - 形態學辨識：十字星、跳空缺口、乖離率、指標頂底背離偵測
  - 均線扣抵推演 / 艾略特波浪自動標註（1-5 浪與 a-b-c 浪）
  - 選股回測勝率驗證器 / 本益比河流圖 / 融資融券籌碼分析

- **Block 2：v11-sector 產業星圖與 AI 決策（window.V11，~4,278 行）**
  - 20+ 台股新興科技族群字典（CPO矽光子、散熱、CoWoS、ASIC、BBU等）
  - 皮爾森相關係數矩陣 Pearson Correlation 與收益率對齊
  - Canvas 純手寫力導向圖（Force-Directed Graph）繪製星圖
  - Ctrl+V 全域截圖 OCR 辨識（Groq / Claude Vision API）
  - AI 釣魚教練 / 即時產業新聞牆與情緒過濾

## 貳、三大核心模組源碼剖析

### 1. Block 0：主控、遊戲引擎與資料管線
- **主迴圈（gameLoop）**：以 
equestAnimationFrame 驅動，每幀計算釣竿角度（updateRod）、天空海洋漸層、波浪與氣泡粒子、魚群深度排序（ishes.sort((a,b) => a.y - b.y)）、游動避障（scared 狀態 3 倍速逃逸），以及甩竿（castHook）碰撞偵測。
- **水深物理對應**：水深底層對應「負乖離過大、超跌打底、低估值折價區」，海面附近對應「突破 20MA、爆量主升段」。
- **大盤鯨魚（Index Whale）**：不可釣起的巨型鯨魚（indexFish），實時綁定加權指數走勢，作為個股相對大盤強弱度的基準座標。
- **Web Audio API 原生合成音效**：使用 AudioContext 的 OscillatorNode 與 GainNode 原生合成甩竿（cast）、釣起（catch）、成就（achievement）與漲停（limitup）音效，免外部音訊資源。
- **稀有度與虛擬組合**：漲停為傳說（legend）、7%為史詩（epic）、5%為稀有（rare）；內置 100 萬本金虛擬投資組合下單與損益追蹤。

### 2. Block 1：v10-extensions 核心量化指標引擎（window.V10）
- **核心指標計算**：DMI、MACD、CCI、OBV、Bias、Fibonacci 黃金分割線、多週期支撐壓力位。
- **形態學與異象辨識**：十字星、晨星、夜星、紅三兵、跳空缺口、指標背離警告。
- **艾略特波浪自動標註**：走訪轉折高低點標註推動浪與修正浪。
- **回測沙盒**：比對 5日、10日、20日、30日前推薦股票之報酬率與勝率。

### 3. Block 2：v11-sector 產業星圖與 AI 決策引擎（window.V11）
- **產業關聯星圖**：以庫倫斥力與虎克彈簧力構建力導向圖，彈簧剛度綁定皮爾森相關係數，兩股走勢越相關在星圖上越靠近。
- **全域截圖 OCR（Ctrl+V）**：監聽全域 paste 事件，提取圖片 Base64 呼叫 Groq/Claude Vision API 自動解析股票放魚。
- **AI 釣魚教練**：接入 Groq API 大模型，結合 30 日價量與籌碼演算關鍵突破點、目標價與防守停損線。

## 參、資料通訊管線與高可用備援架構

三層自動故障轉移機制：
1. **通道 1**：Yahoo Finance TW 排行榜 API（優先取得全市場前 100 名）。
2. **通道 2**：台灣證券交易所（TWSE MI_INDEX）與櫃買中心（TPEx）開放資料。
3. **通道 3**：CORS Proxy 矩陣（corsproxy.io、allorigins、codetabs、jina.ai 等多節點自動輪詢競速）。

## 肆、軟體工程品質評估與重構建議

- **核心亮點**：極致便攜（單檔 1.27MB 跨平台即開即用）、自研原創（手刻 Canvas 圖表與力導向圖，零外部 JS 庫）、互動顛覆（遊戲化外殼包裝專業量化系統）。
- **技術債務**：單檔 2.1 萬行代碼過於龐大、公用 CORS Proxy 的穩定度風險、單線程運算易造成渲染卡頓。
- **重構建議**：工程化拆分模組（Vite + TypeScript）、引入 Web Worker 卸載矩陣運算、自建 Cloudflare Worker 專屬資料中繼代理。
